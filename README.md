Neon Vice: an offline web app that turns your photos and a caption into GTA-poster-style cover art. Six collage layouts (Mosaic, Poster, Quad, Trio, Duo, Solo) with cream keylines, per-panel pan/zoom photo editing, five color grades (Vice Sunset, Neon Night, Golden Hour, Noir, Clean) with grain and vignette, poster lettering in vendored Anton and Bebas Neue, and one-click PNG export at 1080×1080, 1080×1350 and 1920×1080 — the preview canvas is the exact export resolution. Fully static, zero network at runtime, no watermark.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Open `app/index.html` in a browser to use the cover maker itself.
